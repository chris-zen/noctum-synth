# Mini (Planned)

A Raspberry Pi–class model between Micro and Pro, targeting the Raspberry Pi
Zero 2. Boards are out of stock right now; performance will be evaluated once
one can be obtained. Voice count, internal sample rate, and physical I/O remain
TBD until that evaluation.

## Raspberry Pi Zero (discarded)

An earlier attempt targeted the original Raspberry Pi Zero. That path was
discarded because the board could not host even a single voice.
